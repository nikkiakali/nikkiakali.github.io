Job Tracker

AI-augmented system that transforms unstructured job-related email activity into structured application workflow events.

Python GCP Firestore Gmail OAuth LLMs React

System Overview

From Inbox Noise to Structured Signal

Job-related communication is inherently unstructured. Confirmation emails, recruiter follow-ups, rejection notices, and scheduling links arrive across threads with no consistent format. This system ingests that raw email activity, extracts meaningful signals, and maps them to discrete workflow events — application submitted, interview scheduled, offer received — producing a reliable, queryable timeline of each application's lifecycle.

The result is a structured event stream that powers a dashboard where application state remains current without manual data entry.

Engineering Challenges

Hard Problems Worth Solving

Unstructured Inputs

Emails vary widely in format, quoting patterns, and threading conventions. The ingestion layer must normalize this variance before downstream processing can operate reliably.

Event Deduplication

Multiple email threads may reference the same underlying job update. The system must resolve these into singular, canonical events to avoid polluting application state.

Reliable Classification

AI-driven extraction must remain stable across different companies, recruiter styles, and phrasing variations — producing consistent event types from inconsistent inputs.

Design Principles

System Design Philosophy

Event-Driven Architecture

Application state does not live as a single mutable record. It emerges from a stream of extracted events, making the system's history reconstructable and auditable.

Recoverable Automation

Automated signals should always be reversible. Extraction decisions can be reviewed and corrected, ensuring human oversight remains possible at every stage.

Observability First

Extraction pipelines surface granular signals for debugging and evaluation. When classification quality drifts, the system exposes it instead of silently degrading.

Outcome

Why It Matters

Most people manage job searches through mental bookkeeping or fragile spreadsheets. By treating email as a data source rather than only a reading interface, this system converts a chaotic, high-stakes process into a structured, observable workflow. The pattern generalizes beyond job tracking — any domain where asynchronous communication drives state changes can benefit from the same architectural approach.
